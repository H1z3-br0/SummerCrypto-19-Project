# Оптимизация алгоритмов проверки изоморфизма решеток для задач постквантовой криптографии


## Введение

Стремительное развитие квантовых вычислений ставит под угрозу безопасность многих классических криптографических систем, основанных на сложности факторизации целых чисел и дискретного логарифмирования. В связи с этим особую актуальность приобретает разработка и анализ постквантовых криптографических алгоритмов, устойчивых к атакам с использованием квантовых компьютеров. Одним из наиболее перспективных направлений в этой области является криптография на решётках, которая предлагает широкий спектр задач, предположительно сложных даже для квантовых вычислителей [malygina2023postquant], [boer2025lattice].

В то время как большинство современных решёточных криптосистем (таких как Kyber или Dilithium) опираются на вычислительную сложность задач обучения с ошибками (LWE) или задачи нахождения кратчайшего вектора (SVP), существует отдельный класс конструкций, базирующихся на задаче изоморфизма решёток (Lattice Isomorphism Problem, LIP). Задача LIP заключается в нахождении ортонормированного преобразования, переводящего одну решётку в другую. Недавние работы, в частности исследование [ducas2022lattice], продемонстрировали возможность построения криптографических примитивов на основе LIP, что стимулировало новый виток интереса к этой задаче и необходимости глубокого анализа её вычислительной сложности.

Центральным инструментом для решения LIP являются алгоритмы нахождения группы автоморфизмов решётки, среди которых наиболее известным и широко применяемым является алгоритм Plesken–Souvignier [plesken1997computing]. В работе [maloguemfo2018algorithms] приводится модифицированная версия этого алгоритма, которая позволяет находить изоморфизм между решётками. Однако практическая применимость этого алгоритма в контексте криптоанализа наталкивается на вычислительные ограничения. Для достижения приемлемой производительности критически важным является использование методов редукции, таких как алгоритмы LLL и BKZ, которые, однако, сами по себе являются ресурсоёмкими [shary2025curse].

Основная проблема заключается в том, что алгоритм Plesken–Souvignier, несмотря на свою теоретическую значимость, имеет высокую вычислительную стоимость. Дальнейшее исследование должно быть направлено на поиск способов ускорения этого алгоритма, в частности, за счёт совершенствования этапа редукции.



## Цели и задачи

Целью проекта является исследование современных алгоритмов проверки изоморфизма решеток, программная реализация алгоритма Plesken–Souvignier и разработка методов повышения его эффективности. В рамках проекта предполагается изучить математическую постановку задачи изоморфизма решеток и существующие алгоритмы ее решения, реализовать базовую версию алгоритма проверки изоморфизма и провести экспериментальное исследование его вычислительной эффективности. Особое внимание планируется уделить оптимизации наиболее ресурсоемких этапов алгоритма, включая предварительную редукцию базиса с использованием алгоритмов LLL и BKZ. Результатом проекта станет программная реализация алгоритма проверки изоморфизма решеток, исследование эффективности предложенных методов оптимизации и оценка возможности их применения при анализе перспективных криптографических конструкций, основанных на задаче изоморфизма решеток.



## Постквантовая криптография на решётках


Дадим основные определения из теории решёток.


**Определение.**
Пусть $v_1, v_2, \ldots, v_n \in \mathbb{R}^d$ — линейно независимые векторы. **Решёткой** $\mathcal{L}$ называется множество линейных комбинаций вида
```math
\mathcal{L} = \lbrace  \alpha_1 v_1 + \alpha_2 v_2 + \ldots + \alpha_n v_n \mid \alpha_1, \alpha_2, \ldots, \alpha_n \in \mathbb{Z} \rbrace .
```
Числа $d$ и $n$ называются **размерностью** $\dim(\mathcal{L}(B))$ и **рангом** решётки соответственно. При $d = n$ решётка называется **полноранговой**.


**Определение.**
**Базисом решётки** $\mathcal{L}$ называется набор линейно независимых векторов $\mathcal{B}$, порождающий решётку. Соответствующая решётка обозначается через $\mathcal{L}(B)$.


**Определение.**
Матрица $U \in \mathbb{Z}^{n \times n}$ называется **унимодулярной**, если она обратима в группе $\mathbb{Z}^{n \times n}$. Определитель унимодулярной матрицы равен $\pm 1$.


**Определение.**
**Объёмом** решётки $\mathcal{L}$ называется величина $\mathrm{Vol}(\mathcal{L}) = \mathrm{Vol}(\mathrm{Span}(\mathcal{L})/\mathcal{L}) = |\det(B)|$, где $B$ — произвольный базис решётки $\mathcal{L}$.

Также нам потребуются определения билинейных и квадратичных форм.


**Определение.**
Билинейная форма на решётке $\mathcal{L}$ это отображение $\Phi: \mathcal{L} \times \mathcal{L} \rightarrow \mathbb{Z}$, такое что $\forall u, v, w \in \mathcal{L}$ и для любого скаляра $\alpha \in \mathbb{Z}$:
- $\Phi(u, v + w) = \Phi(u, v) + \Phi(u, w);$
- $\Phi(u + v, w) = \Phi(u, w) + \Phi(v, w);$
- $\Phi(\alpha u, v) = \alpha \Phi(u, v); $
- $\Phi(u, \alpha v) = \alpha \Phi(u, v)$

Билинейная форма называется **симметричной**, если $\Phi(x, y) = \Phi(y, x)$ для всех $x, y \in \mathcal{L}$.


**Определение.**
Билинейная форма $\Phi$ называется положительно определенной, если
```math
\forall x \neq 0\ \Phi(x, x) > 0
```

В этой работе мы будем считать, что на решётке $\mathcal{L} = \lbrace  Bx: x \in \mathbb{Z}^{n}, n \in \mathbb{N} \rbrace $ симметричная положительная билинейная форма определяется следующим образом.

Пусть $u = B x,v = By$ вектора решётки $\mathcal{L}$. Тогда определим
```math
\Phi(x, y) = x^{T} B^{T} B y
```

Заметим, что $F = B^{T} B$ - это матрица Грама.


**Определение.**
Квадратичная форма -- это отображение $Q: x \mapsto \Phi(x, x)$, где $\Phi$ -- билинейная форма.

Под коротким вектором решетки $\mathcal{L}$ заданной базисом $B$ мы понимаем вектор $v$, норма которого не превосходит максимума из норм базисных векторов. Все короткие вектора решетки образуют множество $S = \lbrace  v \in \mathcal{L} :  \Phi(v, v) \leq M\rbrace $, где $M$ — максимальная из норм базисных векторов.


**Утверждение.**
Множество $S$, определенное выше - конечно

**Доказательство.**
Доказательство можно найти в [maloguemfo2018algorithms].


**Определение (Последовательные минимумы решётки).**
$\mathcal{L}$ определяются следующим образом:
- $\lambda_1(\mathcal{L}) = \min\limits_{x \in \mathcal{L}, x \neq 0} \lVert x \rVert = \min\limits_{x,y \in \mathcal{L}, x \neq y} \lVert x - y \rVert$;
- $\lambda_i(\mathcal{L}) = \min\lbrace r : \mathcal{L}\text{ содержит } i \text{ линейно независимых векторов длины } \leq r\rbrace $.
Здесь $\lVert x \rVert$ обозначает стандартную евклидову норму в $\mathbb{Z}^n$:
```math
\lVert x \rVert_2 = \sqrt{\sum_{j=1}^n x_j^2}
```

Сформулируем задачи из теории решёток, которые понадобятся нам при описании криптосистемы и реализации атак на неё.


**Определение (Shortest Vector Problem (SVP)).**
Дан базис $B$, найти кратчайший ненулевой вектор в решётке $\mathcal{L}(B)$, то есть такой ненулевой вектор $v \in \mathcal{L}(B)$, что $\lVert v \rVert = \lambda_1(\mathcal{L})$.


**Определение (Автоморфизм решётки).**
Пусть $(\mathcal{L}, \Phi)$ — решётка.
Автоморфизмом решётки называется $\mathbb{Z}$-линейная биекция
$\theta : \mathcal{L} \to \mathcal{L}$, такая что
```math
\Phi(\theta(x), \theta(y)) = \Phi(x, y) \quad \forall x, y \in \mathcal{L}.
```
Группа всех автоморфизмов обозначается $\mathrm{Aut}(\mathcal{L})$.


**Определение (Изоморфизм решеток).**
Две решетки $L$, $L' \subseteq \mathbb{R}^n$ называются изоморфными, если существует некоторое ортонормированное преобразование $O \in \mathcal{O}_n(R)$, такое, что:
```math
L' = O \cdot L.
```

Такое ортонормированное преобразование $O \in \mathcal{O}_n(\mathbb{R})$ иногда называют изометрией.

В вычислительном плане работа производится с базисами решеток, а не с самой $L$. Решетка ранга больше 1 имеет бесконечно много базисов, которые отличаются унимодулярными базисными преобразованиями. То есть два базиса $B$, $B' \in \mathbb{R}^{n\times m}$ порождают изоморфные решетки, если существует некоторое ортонормированное преобразование $O \in \mathcal{O}_n(\mathbb{R})$ и некоторое унимодулярное $U \in GL_m(\mathbb{Z})$, такое, что:
```math
B' = OBU.
```


**Определение (Decision-LIP).**
Даны два базиса $B$, $B' \in \mathbb{R}^{n\times m}$. Необходимо понять, существует ли изометрия $O \in \mathcal{O}_n(\mathbb{R})$ и изменение базиса $U \in GL_m(\mathbb{Z})$, такое, что:
```math
B' = OBU.
```

Заметим, что число генерируемых этим алгоритмом векторов ограничено сверху константой
```math
(2\lfloor \sqrt{Me} \rfloor + 1)\binom{4\lfloor Me \rfloor + n - 1}{4\lfloor Me \rfloor},
```

а также верна следующая

**Теорема.**
Пусть $\mathcal{L}$ — решётка с матрицей Грама $F = (F_{ij})_{1 \leq i,j \leq n}$. Пусть $e^{-1}$ — нижняя граница для элементов $l_{\varepsilon, \varepsilon}$ ($1 \leq \varepsilon \leq n$). Пусть $M$ — максимальная норма базисных векторов решётки $\mathcal{L}$. Тогда алгоритм вычисления коротких векторов решётки $\mathcal{L}$ (с использованием разложения Холецкого) использует не более

Число расширений $k$-частичного автоморфизма
```math
\mathrm{nbExt}(v_1,\dots,v_k)=|\lbrace v\in SN_{k+1}:\Phi(v,v_j)=\Phi(b_{k+1},b_j),\;j=1,\dots,k\rbrace |
```
совпадает с мощностью множества $C_{k+1,k+1}$.



### Fingerprint (отпечаток)

Fingerprint --- верхнетреугольная матрица $f=(f_{ki})$,
```math
f_{ki}=\begin{cases}
0,&i<k,\\
|\lbrace v\in SN_i:\Phi(v,b_j)=\Phi(b_i,b_j),\;j=1,\dots,k-1\rbrace |,&i\ge k.
\end{cases}
```
Элемент $f_{k+1,k+1}$ равен числу расширений тривиального $k$-частичного автоморфизма $(b_1,\dots,b_k)$.
При вычислении $f$ базис переупорядочивается так, чтобы на каждом шаге выбирался вектор с минимальным числом кандидатов (ускоряет поиск с возвратом).

Fingerprint-тест: $k$-частичный автоморфизм $(v_1,\dots,v_k)$ может быть продолжен только тогда, когда
```math
\mathrm{nbExt}(v_1,\dots,v_k)=f_{k+1,k+1}.
```
Это позволяет отсекать бесперспективные ветви уже на ранних этапах поиска.



### Наивный поиск с возвратом vs. поиск с возвратом + fingerprint

Наивный алгоритм перебирает все возможные частичные наборы кандидатов и на каждом шаге проверяет лишь сохранение скалярных произведений.
Алгоритм с fingerprint дополнительно применяет fingerprint-тест, существенно сокращая дерево поиска.

В разделе Algorithms приведен псевдокод алгоритма с fingerprint.



## Изометрии решеток

Напомним, что изометрия двух решёток $(\mathcal{L}_1,\Phi_1)$ и $(\mathcal{L}_2,\Phi_2)$ --- это $\mathbb{Z}$-линейная биекция $g:\mathcal{L}_1\to\mathcal{L}_2$, сохраняющая формы:
```math
\Phi_1(x,y)=\Phi_2(g(x),g(y))\qquad\forall x,y.
```
Множество всех таких отображений обозначается $\mathrm{Iso}(\mathcal{L}_1,\mathcal{L}_2)$.

Ключевое наблюдение:
```math
\mathrm{Iso}(\mathcal{L}_1,\mathcal{L}_2)=\lbrace g\circ\theta\mid\theta\in\mathrm{Aut}(\mathcal{L}_1)\rbrace ,
```
где $g$ --- любая одна изометрия. Поэтому достаточно найти одну изометрию и все автоморфизмы первой решётки.



### Короткие векторы и кандидатные образы

Короткие векторы второй решётки берутся относительно нормы первой:
```math
S_2=\lbrace v\in\mathcal{L}_2:\Phi_2(v,v)\le M_1\rbrace .
```
Множества векторов той же нормы:
```math
SN2_i=\lbrace v\in S_2:\Phi_2(v,v)=\Phi_1(b_i,b_i)\rbrace .
```
На шаге $k$ кандидатный образ $C_{ki}$ --- любой $c\in SN2_i$, удовлетворяющий
```math
\Phi_2(c,v_j)=\Phi_1(b_i,b_j)\qquad(j=1,\dots,k,\;j\neq i).
```

Алгоритмы построения $SN2_i$ и $C_{ki}$ полностью аналогичны случаю автоморфизмов, только скалярные произведения вычисляются по $\Phi_2$, а нормы сравниваются с диагональю $F_1$.



### Наивный алгоритм и алгоритм с fingerprint

Наивный поиск с возвратом перебирает частичные изометрии, проверяя сохранение скалярных произведений.

Алгоритм с fingerprint дополнительно использует fingerprint $f_1$ первой решётки: $k$-частичная изометрия продолжается только тогда, когда
```math
\mathrm{nbExt-iso}(v_1,\dots,v_k)=f_1[k+1,k+1].
```
Это позволяет рано отсекать бесперспективные ветви.

Оба алгоритма могут возвращать либо все изометрии, либо только одну (флаг `one-iso`).



### Практический метод (самый эффективный)

Самый компактный и практически полезный способ --- найти одну изометрию и размножить её автоморфизмами первой решётки.

В секции Algorithms представлен псевдокод алгоритма нахождения изометрий.

Этот метод сочетает скорость fingerprint-поиска одной изометрии с уже вычисленной группой автоморфизмов и на практике оказывается наиболее эффективным.

## Алгоритмы

**Получение множества коротких векторов с помощью разложения Холецкого**
```
\Procedure{$S-\text{elements}$}{$F, M$}
\State $F^* \gets \text{LLL}(F)$
\State $L \gets \text{разложение Холецкого}(F^*)$
\State $n \gets \text{число столбцов в } L$
\State $x \gets [x_1, \cdots, x_n], fillx_n \gets 0$
\State Вычислить $Lb_n \gets \left[ -\dfrac{\sqrt{M}}{l_{nn}} \right]$, $Ub_n \gets \left[ \dfrac{\sqrt{M}}{l_{nn}} \right]$
\State Положить $x_n \gets Lb_n$, $N_n \gets l_{nn} x_n$
\State Положить $U_n \gets 0$, $Y_n \gets 0$, и $k \gets n - 1$
\While{$x_n \le Ub_n$}
\If{$fillx_k = 0$}
\State Вычислить $N_k, U_k$ и $Y_k$ (используя формулы (1), (2) и (3))
\State Положить $x_k \gets Lb_k$
\State $fillx_k \gets 1$
\Else
\State $x_k \gets x_k + 1$
\If{$x_k \le Ub_k$}
\State $k \gets k - 1$
\Else
\State $fillx_k \gets 0$
\State $k \gets k + 1$
\EndIf
\EndIf
\If{$k = 0$}
\While{$x_1 \le Ub_1$}
\If{$x = \text{нулевой вектор}$}
\State append($x, S$)
\State \Return{$S$}
\Else
\State append($x, S$)
\State append($-x, S$)
\EndIf
\State $x_1 \gets x_1 + 1$
\EndWhile
\State $fillx_1 \gets 0$
\State $k \gets 1$
\EndIf
\EndWhile
\EndProcedure
```


**Построение $SN_i$**
```
\Procedure{same-norm}{$F,S$}
\State $D\leftarrow\mathrm{diag}(F)$
\For{$u\in S$}
\If{$\Phi(u,u)\in D$}
\State добавить $u$ во все $SN_i$ с соответствующей нормой
\EndIf
\EndFor
\State\Return $SN$
\EndProcedure
```


**Построение $C_{ki}$**
```
\Procedure{cand-vect}{$F,SN,[v_1,\dots,v_{k-1}],k,i$}
\If{$i<k$}\State\Return $\emptyset$
\Else
\For{$u\in SN_i$}
\If{$\Phi(u,v_j)=F_{ij}$ для всех $j=1,\dots,k-1$}
\State добавить $u$ в $C_i$
\EndIf
\EndFor
\EndIf
\State\Return $C_i$
\EndProcedure
```


**Автоморфизмы с fingerprint**
```
\Procedure{auto}{$F,SN,f$}
\State $Stp\leftarrow SN_1$, $i\leftarrow1$
\While{$i\le n$ и есть неиспробованные кандидаты}
\If{$i<n$}
\For{каждый кандидат $v$ из $Stp$}
\State $L\leftarrow\mathrm{nbExt}(F,SN,[V_1,\dots,V_i,v],i+1,i+1)$
\If{$L=f_{i+1,i+1}$}
\State $V_i\leftarrow v$, $Stp\leftarrow L$, $i\leftarrow i+1$
\State break
\EndIf
\EndFor
\Else
\For{каждый кандидат $v$ из $Stp$}
\If{$(V_1,\dots,V_{n-1},v)$ --- автоморфизм}
\State добавить $(V_1,\dots,V_n)$ в $\mathrm{sol}$
\EndIf
\EndFor
\State backtrack
\EndIf
\EndWhile
\State\Return $\mathrm{sol}$
\EndProcedure
```


**Все изометрии через одну изометрию и $\mathrm{Aut}(\mathcal{L}_1)$**
```
\Procedure{algo-iso-auto}{$F_1,f_1,SN1,F_2,SN2$}
\State $sol\leftarrow[]$
\State $g\leftarrow$ \Call{algo-iso-fingerprint}{$F_1,f_1,F_2,SN2,\texttt{True}$}
\Comment{одна изометрия}
\State $\textit{List-auto1}\leftarrow$ \Call{auto}{$F_1,SN1,f_1$}
\Comment{все автоморфизмы $\mathcal{L}_1$}
\For{$\theta\in\textit{List-auto1}$}
\State добавить $\theta\circ g$ в $sol$
\EndFor
\State\Return $sol$
\EndProcedure
```
